# 图片生成拼豆图工具 PRD

## 1. 背景

拼豆制作通常需要先把用户提供的图片转换成低分辨率网格图，再根据真实拼豆色号逐格摆放。手工处理图片、匹配颜色、统计用量比较耗时，也容易出现颜色不准、尺寸不合适、配豆数量遗漏等问题。

本产品目标是做一个面向拼豆爱好者的图片转拼豆图工具，帮助使用者快速完成从图片到可制作图纸的转换。当前阶段优先保证核心生成、预览、配色和导出能力可用。

## 2. 产品目标

### 2.1 当前目标

- 支持上传图片并生成拼豆图纸。
- 支持选择拼豆品牌/色卡。
- 支持调整图纸尺寸。
- 支持查看配豆清单。
- 支持导出 PNG 图纸。
- 全部处理在本地浏览器完成，图片不上传服务器。

### 2.2 非当前目标

- 不做用户账号体系。
- 不做云端作品保存。
- 不做社区发布。
- 不做多人协作编辑。

## 3. 目标用户

### 3.1 当前用户

拼豆爱好者：自己上传图片，生成拼豆图纸，用于试做、打印、配色、备料和作品分享。

### 3.2 后续潜在用户

- 手工爱好者：用于自助设计拼豆作品。
- 亲子/教学用户：用于快速生成简单拼豆图案。

## 4. 使用场景

### 4.1 图片转拼豆图

用户上传头像、宠物、Logo、动漫图等图片，系统按指定宽度生成拼豆图。

成功标准：

- 图纸尺寸符合设置。
- 颜色被映射为真实拼豆色卡颜色。
- 可以看到每种颜色的用豆数量。
- 可以下载图纸。

### 4.2 调整生成效果

用户通过修改宽度、色卡、抖动开关，比较不同效果。

成功标准：

- 调整参数后图纸能实时重新生成。
- 用户可以直观看到图纸细节和颜色变化。

### 4.3 备料参考

用户查看配豆清单，确定每种颜色需要多少颗。

成功标准：

- 清单包含颜色名称、色块和数量。
- 点击颜色可以在图纸中高亮对应位置。

### 4.4 打印/分享图纸

用户导出 PNG 图纸，用于打印或发送给别人。

成功标准：

- 导出的 PNG 包含拼豆图和颜色清单。
- 网格线和拼板参考线清晰可见。

## 5. 核心流程

```text
打开工具
→ 上传图片
→ 选择拼豆品牌/色卡
→ 调整宽度豆数
→ 选择是否开启抖动
→ 预览拼豆图
→ 查看配豆清单
→ 下载 PNG 图纸
```

## 7. 非功能需求

### 7.1 隐私

- 图片只在浏览器本地处理。
- 不上传原图。
- 不依赖后端服务。

### 7.2 性能

- 普通图片应在秒级生成预览。
- 最大豆数需要限制，避免浏览器卡死。
- 当前实现限制最长边不超过 150 颗豆。

### 7.3 易用性

- 默认提供示例图，方便首次体验。
- 中文页面可直接使用。
- 参数调整后自动刷新结果。

### 7.4 可维护性

- 图像处理、颜色匹配、图纸渲染需要模块化。
- 色卡数据与算法逻辑分离。
- 后续新增色卡不应影响生成流程。
